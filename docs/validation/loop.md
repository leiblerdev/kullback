# Learning Loop

The loop that runs until we learn enough. Priority: **speed**.

## The cycle

1. **Find**: pull profiles (warm network + CDTM/Munich AI).
2. **Qualify**: is this a good reach-out? (checklist below).
3. **Reach out**: draft + send (LinkedIn first).
4. **Talk**: run the interview (`interview-guide.md`).
5. **Log + add**: record in `progress.md`; update `prospects.csv`.
6. **Update hypotheses**: confirm / kill / polish / generate in `hypotheses.md`.
7. **Solve + validate**: try to solve their problem (the concierge report) while validating.
8. **Repeat.**

## Qualify (is this a good reach-out?)

Hard requirements (ALL, no exceptions; see `gtm/docs/criteria.md`):

- **Spend**: > $25k/month LLM API spend. Below this they say "too small".
- **Decision-maker**: founder, CTO, or founding engineer (feels the cost AND can approve). Required, not a preference.
- **AI-native**: LLM is core to the product (agent/copilot), not a side feature.

Prioritize (rank higher):

- **Feels it now**: steering to profitability (Series B+), bootstrapped / PE-owned, or hitting monthly credit limits ("we run out of credits every month").
- **Heavy workload**: multi-step agents, voice, coding, document/legal, high-volume support.
- **Live**: production traffic, not stealth / pre-launch.
- **Reachable**: warm > 2nd-degree > cold.

Fail any hard requirement → skip. Don't waste the interview.

## Stop criteria ("enough")

Run until BOTH:

1. **Pain confirmed (H2)**: ≥3 independent founders describe a *past* triggering moment with specifics.
2. **6 Partial Customers**: 6 founders have sent traces / committed to the report.

Then: stop validating → build the website + wrapper → convert partials to **Final Customers** (paying).

## Speed rules (run fast)

- **Parallel, not sequential:** warm DMs out today; cold research + outreach starts the same day. Never wait for replies to start the next batch.
- **LinkedIn DM first** (fastest reply), email as backup.
- **Compressed cadence:** send → nudge day 2 → break-up day 5.
- **One-click booking:** `https://cal.com/fokkerlabs/introduction` in every message.
- **Pre-draft everything** upfront: zero friction between "list ready" and "sent."
- **Bigger batches:** 10–15 cold per round.
- **Book same-day:** reply in the morning → meeting booked by afternoon.

## Division of labor

- **Agent (me):** research leads, qualify, draft outreach, update hypotheses + docs after each round, propose next questions.
- **You:** review + send messages, run the calls, paste back raw notes.

## Evidence rules

- A past action with specifics = evidence. A compliment or future promise = noise.
- One "no" from a warm contact is not a kill. Three independent "we don't feel this" is.
