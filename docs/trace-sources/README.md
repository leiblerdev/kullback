# Trace sources

Public trace datasets Kullback could build an Environment from, one page each. Use it to pick the next corpus:
each page says what a row is, its licence, how to download it and how well it fits our Trace record.
[eligibility.md](eligibility.md) scores them all on one test (tool calls and results, a runnable environment,
several runs per task, a licence, real provenance, replayable state).
